# XIDONKANA-CATERING-SERVICE-
🍽️ XidonkaNa Catering Service Website
Welcome to the XidonkaNa Catering Service website!
This project is a simple, responsive web platform designed to showcase catering services, menus, and contact information for potential customers.

📌 Overview
The XidonkaNa Catering Service website provides users with an easy way to:

Learn about the catering business
Browse available food services
View menus and offerings
Contact the business for bookings or inquiries

This project is ideal as a small business website or portfolio for a food/catering service.

🚀 Features

✅ Responsive design (works on mobile, tablet, desktop)
✅ Clean and modern layout
✅ Service/menu section
✅ Contact section
✅ Easy navigation


🛠️ Technologies Used

HTML5 – Structure of the webpage
CSS3 – Styling and layout
JavaScript (optional) – Interactivity (if included)
